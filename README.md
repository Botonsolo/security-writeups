# 🔐 Security Write-ups

A collection of my hands-on security work, split into four categories:

- **[`CTFs/`](./CTFs)**: Offensive security exercises covering enumeration, exploitation, privilege escalation, and post-exploitation analysis on intentionally vulnerable machines (HackMyVM, VulnHub).
- **[`Sherlocks/`](./Sherlocks)**: Hack The Box Sherlocks. Defensive and DFIR challenges focused on log analysis, incident triage, and threat hunting.
- **[`Forensic-Analysis/`](./Forensic-Analysis)**: Digital forensics and incident response reports (PDF) covering evidence handling, chain of custody, timeline reconstruction, and root cause analysis.
- **[`Tips/`](./Tips)**: Practical tips and advice that have helped me in my investigations.

Each report follows a consistent structure so findings are easy to compare, and evidence-based conclusions are clearly separated from analysis.
